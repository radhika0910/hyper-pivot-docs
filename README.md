# Hyper-Pivot Documentation

A modern, interactive documentation site for the [hyper-pivot](https://www.npmjs.com/package/hyper-pivot) library, built with React, TypeScript, and Vite.

## Features

- ⚡ **Fast Development** - Powered by Vite for instant HMR (Hot Module Replacement)
- 🎨 **Modern UI** - Built with Material-UI (MUI) components
- 📝 **TypeScript** - Full type safety and better IDE support
- 🎯 **Interactive Examples** - Live demonstrations of hyper-pivot functionality
- 📱 **Responsive Design** - Works seamlessly on all screen sizes

## Tech Stack

- **Framework**: React 18.3
- **Language**: TypeScript 5.6
- **Build Tool**: Vite 6.0
- **UI Library**: Material-UI 6.0
- **Package Manager**: npm

## Installation

```bash
npm i
```

This installs all dependencies including the published hyper-pivot package from npm.

## Available Scripts

### Development
```bash
npm run dev
```
Starts the development server. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### Build
```bash
npm run build
```
Compiles TypeScript and builds the project for production in the `dist` directory.

### Preview
```bash
npm run preview
```
Preview the production build locally.

## Project Structure

```
src/

└── propData.ts      # Property data and configurations
index.html           # HTML template
package.json         # Project dependencies and scripts
tsconfig.json        # TypeScript configuration

```

## Getting Started

1. Clone or download this project
2. Run `npm i` to install dependencies
3. Run `npm run dev` to start the development server
4. Start editing files - changes will hot reload automatically
